Installation Instructions

Follow these steps to load the unpacked Chrome extension:

  1. 1

    Download the Extension

    Click the download button above to download the nabu-ai-plus-extension.zip file.

  2. 2

    Extract the ZIP File

    Extract the downloaded ZIP file to a location on your computer. You'll need to remember this location.

  3. 3

    Open Chrome Extensions Page

    Open Google Chrome and navigate to the extensions page by:

    • Typing chrome://extensions/ in the address bar, or
    • Going to Menu (⋮) → Extensions → Manage Extensions
  4. 4

    Enable Developer Mode

    Toggle the "Developer mode" switch in the top-right corner of the extensions page.

  5. 5

    Load Unpacked Extension

    Click the "Load unpacked" button that appears after enabling Developer mode.

  6. 6

    Select the Extension Folder

    Navigate to and select the folder where you extracted the extension files (the folder containing manifest.json).

  7. 7

    Start Using Nabu AI

    The extension should now appear in your extensions list. Click the extension icon in your Chrome toolbar to get started!

Troubleshooting

The extension won't load

Make sure you've extracted the ZIP file and are selecting the folder containing manifest.json, not the ZIP file itself.

I see an error message

Check the Chrome extensions page for error details. Common issues include missing files or incorrect folder structure.

The extension icon doesn't appear

After loading, you may need to pin the extension to your toolbar. Click the puzzle icon in Chrome's toolbar and pin Nabu AI Plus.
